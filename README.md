Правила игры:

- Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы.
- Все 16 карточек перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8.
- Игрок сразу может открывать карточки.
- Игрок открывает одну карточку, затем другую. Один ход — открытие двух разных доступных карточек, независимо от того, совпали они или нет.
- Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар увеличивается на 1.
- Если изображения различаются, обе карточки остаются видимыми примерно секунду, затем закрываются.
- Пока игрок рассматривает несовпавшую пару, открыть другие карточки нельзя.
- Когда найдены все 8 пар, игра завершена. Автоматически окно с сообщением о победе, итоговым количеством ходов и кнопками «Новая игра» и «Закрыть».
- В верхней части приложения расположены кнопки «Новая игра» и «Таблица лидеров».
- «Новая игра» начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются.
- «Таблица лидеров» открывает сохранённые результаты в модальном окне.

Инструкция по локальному запуску приложения:

- Клонировать репозиторий по [ссылке](https://github.com/volsashgeo/memory-game) из VSCode.
- Перейти в папку игры командой cd memory-game из терминала.
- перейти в ветку memory-game командой git checkout memory-game или git switch memory-game.
- Запустить Live Server и наслаждаться игрой
